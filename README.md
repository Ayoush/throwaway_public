# Throwaway Kanban

A small React task board used as a throwaway codebase for testing the Intervues mentors pipeline. Tasks live in the browser via a local API (`src/api/tasks.js`) backed by `localStorage`. There is no backend, auth, or database.

## Getting Started

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`). The app loads a handful of sample tasks and lists them on the board.
